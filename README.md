# ⚖️ Detecção de Cláusulas Abusivas

> Detecção de cláusulas abusivas em contratos de consumo com NLP. Protege o consumidor identificando violações ao CDC automaticamente.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/clausulas-abusivas/

## 📊 Resultados-chave (KPIs)
**96%** Detecção · **analisadas** Cláusulas · **flag** Violações CDC · **escala** Contratos

## 🧠 Tecnologias de IA
NLP · LLM · CDC

## ✨ O que faz
- Detecção de abuso (CDC)
- Análise de contrato de adesão
- Score de risco ao consumidor
- Sugestão de revisão

## 🗄️ Fonte de dados real
[CDC + jurisprudência](https://www.gov.br/mj)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com CDC + jurisprudência
2. **Processamento com IA** — NLP · LLM · CDC
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
